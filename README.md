# Manim Visualizations

Минимальная инфраструктура для генерации математических анимаций на Python + Manim.

## Что уже подготовлено

- Виртуальное окружение `.venv` (Python 3.13).
- Установлены зависимости для Manim.
- Базовая сцена по центральной предельной теореме:
  `scenes/central_limit_theorem.py`.

## Быстрый старт

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

## Рендер сцены

Быстрый превью-рендер (низкое качество):

```bash
manim -pql scenes/central_limit_theorem.py CentralLimitTheoremScene
```

Более качественный рендер:

```bash
manim -pqh scenes/central_limit_theorem.py CentralLimitTheoremScene
```

Результаты сохраняются в папке `media/`.

## Инструкция для следующего агента

Ниже рабочий процесс, по которому нужно добавлять новые визуализации в этот проект.

1. Создай новую сцену в папке `scenes/`.
2. Дай классу сцены понятное имя в стиле `SomethingScene`

Пример команды:

```bash
manim -pql scenes/<file_name>.py <SceneClassName>
```

## Очистка промежуточных файлов

Manim генерирует много артефактов в `media/` и кэш в `.manim/`.
Если нужно почистить проект после экспериментов:

```bash
rm -rf media .manim
```

Если нужно удалить только промежуточные куски видео, но оставить финальные `.mp4`:

```bash
find media/videos -type d -name "partial_movie_files" -prune -exec rm -rf {} +
```

Примечание: команда `rm -rf` удаляет без корзины, используй осознанно.

## Структура проекта

- `scenes/`:
  исходные Python-сцены Manim.
- `requirements.txt`:
  зафиксированные зависимости Python.
- `.venv/`:
  локальное виртуальное окружение.
- `media/`:
  результат рендера и служебные файлы Manim.

## Что лежит в `media/`

- `media/videos/<scene_file>/<quality>/`:
  финальные видео (`.mp4`) и промежуточные видеофрагменты.
- `media/videos/.../partial_movie_files/`:
  служебные куски по анимациям, из которых Manim склеивает итоговый ролик.
  Можно удалять после рендера.
- `media/texts/*.svg`:
  закэшированные векторные контуры для `Text` (слова, подписи, заголовки).
  Это не исходники, а промежуточные артефакты, их можно удалять.
- `media/Tex/*.tex` (и иногда `.svg`, `.dvi`, `.log`):
  временные файлы для `Tex/MathTex`, если сцена использует LaTeX.
  Если TeX не используется, папка может быть пустой или со старыми остатками.
- `media/images/`:
  экспортированные кадры/изображения (если сцена или команда их генерирует).

Итого: всё внутри `media/` можно безопасно пересоздать повторным рендером.
